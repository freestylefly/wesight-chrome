# WeSight 发布助手

WeSight Obsidian 插件的浏览器配套扩展。扩展复用 Chrome、Edge 或 Arc 中已有的平台登录状态，将当前内容准备到知乎、CSDN、掘金、B站专栏、今日头条、微博头条文章、X 文章与动态、小红书图文、微博图文动态和即刻动态编辑页。所有平台的最终发布操作均由用户在页面中确认。

## 发布中心

发布中心包含「动态」和「文章」两种模式，两类草稿分别保存在本机，切换时保留编辑内容。

### 动态

无需连接 Obsidian，也能直接填写正文、添加话题，选择图片或一个视频，分发到小红书、微博、即刻和 X。可以使用统一文案，也可以分别编辑每个平台的标题、正文、话题和图片顺序。小红书需要标题及图片或视频；微博、即刻和 X 支持纯文字。小红书、微博、即刻当前最多同步 9 张图片，单张不超过 10 MB；视频不超过 200 MB，并需符合目标平台自身的格式和时长要求。图片与视频分开发送。

X 动态复用浏览器登录态，在 X 原生 Post 编辑窗口中准备文案和图片，由你确认发布。支持最多 4 张 PNG、JPEG、WebP 图片，单张不超过 5 MB；不支持的图片格式会跳过并提醒，原稿和其他平台图片保留。话题默认不同步到 X（正文里手写的 #话题 会保留）；标题与正文合并后采用 X 官方文字计数规则检查 280 字符，中文通常计 2、链接按缩短后的长度计数；超长请在「分平台编辑 → X」单独精简，超出 4 张时也可在这里调整 X 的图片。X 视频当前会明确阻止，其他三平台的视频同步仍可使用。

X 动态的文案通过 X 原生 Post 文字链接预填，扩展只读确认编辑框中的完整文案；带图动态在文案就绪后，把图片文件交给 Post 窗口自带的图片上传入口，由 X 自己上传，与手动选择图片相同。扩展不点击任何按钮，不调用发帖接口，也不使用 X 内部草稿或媒体接口。已有未发布内容时会暂停，避免覆盖；同一页面重试会保留已装入的图片和你在 X 内的修改。X 文章与动态共用账号识别，无已打开页面时只读检查一个后台 X 主页。本机只保存任务内容摘要、账号标识和完成状态。

在 Obsidian「转为图文 → 快速转」生成平台文案后，点击一键发布，会打开浏览器的「动态」模式，带入小红书、微博、即刻和 X 的独立文案、图片及即刻圈子。检查内容并点击「开始同步」后才会打开平台编辑页。视频同步会等待平台上传和处理完成，再显示待发布状态；最终发布仍由用户手动确认。

### 文章

在 Obsidian 点击「多平台发布」后，扩展会打开「发布中心」标签页并带入当前文章。发布中心支持三种导入方式：

1. Obsidian：标题、摘要、封面、正文和图片自动带入。
2. 本地 Markdown：选择 `.md` 文件，可连同正文引用的图片一起选择或拖入，图片按文件名匹配，支持 `![[图片]]` 写法和 frontmatter 中的 `title`、`tags`、`cover`。
3. 文章链接：读取网页正文并下载其中的图片，公众号文章会读取标题、摘要和封面。首次使用会请求读取网页的权限。

导入后可以修改标题、摘要、封面和 Markdown 正文，勾选平台并开始同步。平台卡片会显示浏览器中的登录账号和同步进度，失败或需要登录的平台可以单独重试。发布中心会自动读取当前账号接口及已打开的 CSDN、微博、X 页面的账号标识，无需手动新开页面检测；暂时无法确认时可在卡片内重新检测，网络失败不会直接视为未登录。浏览器插件使用与 Obsidian 相同的 WeSight 账号体系，右上角显示头像和昵称，支持登录、退出与登录失效检查；也可从已配对的 Obsidian 验证同一账号。普通用户每次同步 1 个平台，WeSight 会员可多选。点击工具栏图标后选择「打开发布中心」也能进入。

平台勾选与是否保留正文图片会记住，下次导入或重新打开发布中心时自动恢复。封面默认使用正文第一张可用图片，也可选择其他正文图片、上传新封面或明确移除。正文预览复用公众号「苍绿」主题，预览装饰不会写进平台草稿。文章开头的居中背景标记（例如原创篇数）在导入和同步时清理，正文里的 HTML 示例保持原样。

平台暂未确认登录或已经退出时，卡片显示「去登录」。点击后打开对应平台，已有页面会直接聚焦，保留其中编辑的内容。登录页会在本次浏览器会话中持续检测最多 10 分钟，支持无需跳转的扫码登录；识别成功后自动更新发布中心的账号状态和可获取的昵称，无需手动重新检测。检测只读取账号入口与编辑器是否可用，不会操作登录表单或发布内容。

即刻支持当前网页版的图标导航识别，首页没有显示昵称、头像或编辑弹窗时也能确认登录。没有打开即刻页面时，扩展会临时在后台打开首页进行只读检测，完成后清理；已有页面直接复用，用户已切换到检测页时保留页面。加载或网络异常会保持“暂未确认登录状态”。

小红书读取创作服务平台当前顶部账号的昵称和头像；没有打开创作中心页面时，临时在后台打开创作中心首页确认会话，完成后清理。已打开的页面直接复用，检测期间不操作草稿或上传控件。普通小红书网站的登录状态不会直接视为创作中心已登录。

X 文章复用当前浏览器的 X 登录态，通过 X 网页内部接口上传图片、创建包含标题和正文的草稿并设置封面，完成后打开草稿编辑页，由用户确认发布。同步过程不点击或填充 X 页面控件，不调用发布接口；接口配置缺失时直接报告错误。网络结果不确定时停止重复创建；封面失败后重试会复用同一草稿。内部接口可能变化或触发平台限制，不保证账号免于风控。图片支持 JPEG、PNG、WebP，单张不超过 5 MB。只有勾选 X 时才检查 15 张图片上限；超限提示右侧可勾选“自动跳过超出图片，保留全部文字”，按正文顺序保留前 15 张图片，其余图片仅从 X 草稿中移除，全部文字与其他平台内容保留。独立封面占用一个名额，此时保留前 14 张正文图片和封面。该选项会记住；未勾选时继续阻止超限同步。X 账号需要拥有文章功能权限，平台说明见 [X Articles](https://help.x.com/en/using-x/articles)。

## 本地开发

```bash
pnpm install
pnpm dev
```

Chrome 安装步骤：

1. 下载并解压 `wesight-chrome.zip`。
2. 在地址栏打开 `chrome://extensions/`。
3. 开启右上角「开发者模式」。
4. 点击左上角「加载已解压的扩展程序」，选择解压后直接包含 `manifest.json` 的文件夹；也可以把该文件夹拖入扩展管理页。

Edge 可在 `edge://extensions/` 按相同步骤加载解压后的扩展文件夹。安装后，WeSight 有效会员可在 Obsidian「设置 → WeSight → 通用 → 连接器」点击浏览器发布助手的「连接浏览器」，完成本机配对；非会员会收到开通会员提示。连接操作只建立通道，不会导入笔记或创建发布任务；成功后回到图文工作台继续发送。未连接时，发送操作会先打开连接器设置并保留编辑内容。Obsidian 重启后若本机通道地址变化，可在同一设置卡片重新连接。

扩展通过浏览器定时任务每分钟确认本机通道，Obsidian 关闭后每五分钟安静重试。断开后重新连接会立即检查，无需等待定时任务。

Arc 可在 `arc://extensions/` 加载 Chrome 安装包。扩展会逐个激活平台页，使每个草稿都进入当前 Space 的侧边栏；任务面板中的「打开全部草稿」可以恢复被 Arc 收起或关闭的草稿页。

1.1.0 建议配合 [WeSight for Obsidian 1.4.0](https://github.com/freestylefly/wesight-obsidian/releases/tag/1.4.0) 使用。Obsidian 的「转为图文」、浏览器连接与多平台交接需有效会员；浏览器独立发布中心保留普通用户每次同步 1 个平台、会员多选的规则。已安装用户更新原目录文件后，需要在扩展管理页重新加载扩展。完整更新内容见 [1.1.0 更新说明](docs/releases/1.1.0.md)。

## 构建

```bash
pnpm check
pnpm package
```

构建和 ZIP 产物位于 `build/`。Chrome 与 Edge 分别使用 `chrome-mv3-prod` 和 `edge-mv3-prod` 目录。

## 安全边界

- 本地通道仅监听 `127.0.0.1`，正文与图片不经过 WeSight Cloud。
- 扩展不申请 Cookie 权限，直接复用平台页面已有的登录状态。
- 任务令牌有效期为 10 分钟，只保存在浏览器会话中。
- 发布中心分别保留一份文章草稿和一份动态草稿，正文、图片及视频存放在扩展自己的 IndexedDB 中；导入新内容时替换对应模式的草稿。
- 扩展不会点击发布按钮，也不会调用平台正式发布接口。
- 诊断日志最多保留 100 条，并对令牌及密钥字段脱敏。

平台页面结构更新后，单个平台可能需要更新适配器。失败状态会保留在 Popup 和 Obsidian 任务面板中，用户可以登录后重试。

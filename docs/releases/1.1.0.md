# WeSight 发布助手 1.1.0

发布中心支持直接编辑动态、导入文章和独立登录 WeSight，新增 X 文章与动态，并改善账号识别、视频准备及多平台任务恢复。各平台的最终发布操作仍由你确认。

## 发布中心

- 新增「动态 / 文章」双模式，各自保留本机草稿，重新打开和切换模式后继续编辑。
- 动态支持小红书、微博、即刻与 X，可统一文案或分平台调整标题、正文、话题及图片顺序；「新内容」可开始下一条并保留已选平台。
- 小红书、微博和即刻支持单个视频准备，等待平台上传处理完成后显示状态；X 动态当前支持文字及最多 4 张图片。
- 文章支持从 Obsidian、本地 Markdown 及文章链接导入，包含正文图片和封面选择，提供「苍绿」主题预览。
- 支持独立登录、退出 WeSight 及会员状态刷新。浏览器独立编辑时，普通用户每次同步 1 个平台，会员支持多选。

## X 与平台体验

- 新增 X 文章草稿同步，支持标题、正文、图片与封面，提供超限图片处理选项；需要目标账号拥有 X 文章功能。
- 新增 X 动态：文案使用 X 原生 Post 文字链接预填，图片交给该窗口的原生文件入口，由你检查后发布。
- X 动态默认不追加话题字段，正文内手写的话题保留；按 X 官方文字计数规则校验长度。
- 改善 X 在后台同时加载多平台时的等待，切回 X 后自动继续；重试保留已准备的图片和手工修改。
- 改善小红书、即刻、微博与其他平台的登录识别、账号显示和上传进度；可跳转登录并自动更新检测结果。
- 保留导入稿、失败任务与各平台状态，支持重试和重新打开草稿页。

## 安装与升级

- Chrome 与 Arc 下载本 Release 的 `wesight-chrome.zip`，Edge 下载 `wesight-edge.zip`，解压后保留整个文件夹。
- Chrome 打开 `chrome://extensions/`，Edge 打开 `edge://extensions/`，开启「开发者模式」，选择「加载已解压的扩展程序」并选中直接包含 `manifest.json` 的目录。
- 已安装用户请更新原扩展目录中的文件，在扩展管理页点击重新加载，并刷新已打开的平台页；浏览器若提示新增站点权限，请检查后确认。
- 建议同时更新 [WeSight for Obsidian 1.4.0](https://github.com/freestylefly/wesight-obsidian/releases/tag/1.4.0)。Obsidian 的「转为图文」、浏览器连接与多平台交接需有效会员，非会员会收到开通会员提示。
- 原有本机配对继续复用；首次配对在 Obsidian「设置 → WeSight → 通用 → 连接器」中完成。

## 隐私与发布边界

- 正文及素材保存在本机草稿库，由本机通道交接或上传至你选择的平台，内容不经过 WeSight Cloud；WeSight 登录及会员校验使用官方账号接口。
- 复用浏览器已有的平台登录状态，不申请 Cookie 权限；导入文章链接时按需请求读取该网页的权限。
- 扩展准备编辑内容或草稿，不点击平台发布按钮，不执行最终发布操作。
- 平台页面或内部接口更新可能影响适配，发布前请检查正文、图片、账号与平台要求。

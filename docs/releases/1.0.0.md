# WeSight 发布助手 1.0.0

配合 WeSight for Obsidian 1.0.0，将文章和图文动态准备到多个平台，复用当前浏览器登录状态，最终发布由你确认。

## 新增平台

- 今日头条：准备图文文章，填充标题、正文和图片。
- 微博头条文章：上传正文图片与封面，创建并保存草稿，支持返回对应草稿编辑页。
- 小红书图文：按顺序批量上传图片，填写标题、正文和标签。
- 微博图文动态：填写正文与话题，上传多张配图。
- 即刻动态：填写正文与图片，支持圈子选择提示。
- 保留知乎、CSDN、掘金和B站专栏支持，共覆盖 9 类发布目标。

## 新增：快速转批量任务

- 接收 Obsidian「快速转」一次生成的多个平台内容，每个平台使用自己的文案和图片集合。
- 兼容统一文案与不同文案模式，避免批量任务只处理小红书或混用平台内容。
- 扩展 Popup 汇总账号与任务状态，相关页面放入同一标签组，可打开编辑页并重试失败任务。

## 体验改进与修复

- 改进微博、即刻的图片上传完成识别，减少图片已完成却仍显示上传中的情况。
- 改善即刻正文的段落与空行保留。
- 按平台处理标签：小红书 `#标签`，微博 `#标签#`，即刻不追加标签。
- 小红书采用任务触发的单次填充方式，不长期驻留监听或插入扩展进度浮层，上传过程使用平台原生界面。
- 支持真实编辑页地址回传、任务恢复与重试，并对缺失控件、登录失效和部分上传失败给出明确状态。

## 安装与升级

- Chrome 下载本 Release 的 `wesight-chrome.zip`，Edge 下载 `wesight-edge.zip`，解压后保留整个文件夹。
- Chrome 打开 `chrome://extensions/`，Edge 打开 `edge://extensions/`，开启「开发者模式」，点击「加载已解压的扩展程序」，选择直接包含 `manifest.json` 的文件夹。
- 已安装用户请更新原扩展目录中的文件，并在扩展管理页点击重新加载；如果浏览器提示新增站点访问权限，请检查后确认。
- 请同时更新 [WeSight for Obsidian 1.0.0](https://github.com/freestylefly/wesight-obsidian/releases/tag/1.0.0)。首次任务按引导完成本机配对，后续复用配对信息。

## 隐私与发布边界

- 正文和图片从 Obsidian 经由本机临时通道传给扩展，再上传到你选择的平台，不经过 WeSight Cloud。
- 仅申请存储、标签页、脚本执行、标签分组及所支持平台的站点权限，不申请 Cookie 权限和全站访问权限。
- 不执行最终发布操作，不点击平台发布按钮。请在各平台检查文案、图片顺序、分类和声明后手动发布。
- 本版不包含 X Articles、视频、定时发布或多账号切换。平台页面更新可能影响适配，遇到问题可保留任务状态并反馈。

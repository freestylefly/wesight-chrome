# WeSight 发布助手 1.2.0

新增诊断能力，方便测试者和用户反馈问题。

- 新增“诊断”页（弹窗底部入口）：显示插件版本、构建号、安装方式、浏览器与系统、已授权站点、Obsidian 配对和 WeSight 登录状态。
- 新增“平台自检”：逐个平台检测登录状态，并列出检测方式、HTTP 状态、最终网址（仅域名和路径）、接口返回码和耗时。
- 新增“导出诊断包”：记录登录检测过程、草稿填充步骤与耗时、匹配到的页面元素、失败时的页面结构统计、图片上传大小和结果、重定向循环、重试、权限失败及插件自身报错。
- 隐私：不记录文章正文、标题、标签、图片和文件名，不记录 Cookie、令牌和网址参数；账号昵称只记是否读到，最多显示首字加星号。诊断包只保存在本机，由用户决定是否发出，扩展不会自动上传。
- 构建时写入提交号和构建时间，便于定位测试包版本。

安装和升级步骤见仓库 README。现有本机草稿和配对记录继续使用。

## 名称

WeSight 发布助手

## 简短描述

从 Obsidian、本地 Markdown 或文章链接导入内容，为多个内容平台准备文章与动态草稿，最终发布由你确认。

## 单一用途描述

将用户主动提供的文章或动态内容准备为所选内容平台的草稿：导入并编辑正文与素材，复用用户已登录的平台账号，填充编辑器、上传素材或保存草稿，供用户在平台页面检查并手动发布。

## 长介绍

WeSight 发布助手帮助内容创作者把一份文章或动态准备到多个平台，减少重复复制、排版和上传素材的操作。检查好各平台草稿后，由你完成最终发布。

【文章草稿】

支持从本地 Markdown 文件、文章链接或已配对的 WeSight Obsidian 插件导入文章。导入后可修改标题、摘要、封面和正文，预览内容，再同步到知乎专栏、CSDN、掘金、B站专栏、今日头条、微博头条文章和 X 文章。

【动态草稿】

直接填写文案，添加本地图片或视频，同步到小红书、微博、即刻和 X。可以使用统一文案，也可以为各平台分别调整标题、正文、话题和图片顺序。文章与动态草稿分别保存在本机，重新打开发布中心可继续编辑。

【账号与进度】

复用浏览器中已有的平台登录状态，显示可检测到的账号信息和同步进度。需要登录或发生错误时，可以打开平台页面处理后单独重试。内容就绪后，前往平台编辑页检查并手动发布。

【使用条件与收费】

扩展可免费下载。开始平台同步需要登录 WeSight；普通账号每次可同步 1 个平台，WeSight 有效会员可在同一次任务中选择多个平台。会员通过 WeSight 网站购买，实际价格和权益以购买页为准。浏览器独立发布中心可直接使用；从 Obsidian 连接、导入及交接内容需要配套 WeSight Obsidian 插件和有效会员。

各内容平台需要你自己的账号和相应创作权限。X 文章需要该账号已开通 X 文章功能；WeSight 会员不会为第三方平台提供创作权限。

【当前限制】

小红书、微博和即刻动态当前最多同步 9 张图片，单张不超过 10 MB；视频不超过 200 MB，并受目标平台格式和时长限制。图片与视频分开发送。X 动态支持纯文字或最多 4 张图片，单张不超过 5 MB，暂不支持视频；文字按 X 的 280 字符规则校验。X 文章最多使用 15 张图片，独立封面计入名额，可选择跳过超出图片并保留文字。实际同步结果还受平台页面、接口和账号权限影响。

【隐私与权限】

Obsidian 内容通过本机通道导入，扩展不会把正文、图片或视频上传到 WeSight Cloud。开始同步后，内容和素材会发送给你选择的平台；链接导入会请求你提供的文章网站及图片来源。WeSight 账号服务用于登录和会员权益校验。

扩展在本机保存草稿、附件、账号状态、操作偏好和有限任务诊断信息；登录令牌按长期存储或浏览器会话分别保存。网站访问权限用于读取文章、识别平台登录状态及准备草稿。扩展不收集平台密码，不读取完整浏览历史，不执行最终发布。移除扩展可清除本机扩展数据；平台端草稿和云端账号数据需分别处理。

WeSight 发布助手为独立产品，与所支持的内容平台无官方隶属或授权背书关系。平台页面或内部接口更新可能影响适配，我们会持续维护。

## 隐私实践填写依据

本地处理也应披露。以下按当前源码记录数据类别，后台以实际显示的选项名称为准；不要选择“完全不收集或使用任何用户数据”。

| 数据类别 | 当前处理情况 | 用途 |
| --- | --- | --- |
| 个人身份信息 | WeSight 用户 ID、昵称、头像；平台昵称、头像及账号标识 | 账号识别、展示及任务绑定 |
| 身份验证信息 | WeSight 访问/刷新令牌、配对密钥、任务访问令牌；临时使用平台页面可读 CSRF 值 | 登录、权益校验、配对、平台草稿请求 |
| 网站内容 | 用户导入或填写的标题、正文、图片、视频、平台独立文案，以及为同步而核对的编辑器内容 | 草稿导入、编辑、保存、同步和重试 |
| 网页浏览记录／网址相关信息 | 保存用户主动提供的文章来源 URL 和本任务草稿地址；查看相关标签页 URL 以定位平台、处理登录与恢复任务 | 实现用户发起的导入、登录和同步功能；不建立其他网页的访问历史 |
| 财务和付款信息 | 扩展查询会员、套餐、有效期和积分摘要；不读取银行卡或付款账户凭据 | 展示与校验可用权益。后台若将购买/订阅状态归入此类，应将该摘要一并披露 |

用途为扩展功能及相应维护；不出售数据，不用于个性化广告，不用于信用评估，不训练通用人工智能模型。扩展没有自动上传本机诊断日志的功能。人工排障时，请用户仅提供必要且已脱敏的信息。

Limited Use 中文声明：WeSight 发布助手对通过浏览器扩展获得的信息的使用和转移遵守 Chrome Web Store User Data Policy，包括其中的 Limited Use 要求。

Limited Use 英文声明：The use and transfer of information received by WeSight Publish Assistant will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

隐私政策使用仓库根目录的 `PRIVACY.md`。先将最终政策发布到无需登录即可访问的 HTTPS 地址，再将该实际地址填写到商店隐私政策字段；可使用公开仓库正式提交中的文件永久链接。

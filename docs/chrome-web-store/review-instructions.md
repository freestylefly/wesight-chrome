# Chrome Web Store 审核说明

本文件包含功能测试说明和开发者提交前准备事项。测试账号凭据应通过 Developer Dashboard 的私密测试说明提供，勿提交到仓库、商店长介绍或公开 Issue。

## 本次提交

## 功能与付费说明

WeSight 发布助手的单一用途是将用户主动提供的文章或动态内容准备成所选平台的草稿。扩展会填入编辑器、上传素材或保存草稿；审核期间无需点击任何平台的最终发布按钮。

浏览器独立发布中心不依赖 Obsidian。开始同步需要登录 WeSight：普通账号每次可选择 1 个平台，有效会员可选择多个平台。会员功能需付费。Obsidian 的本机连接和内容交接另需 WeSight Obsidian 插件及有效会员。各第三方平台仍需要具备创作权限的独立账号，X 文章另需 X 账号具有文章功能权限。

## 基础测试：本地内容与草稿保留

1. 点击扩展工具栏图标，再点击「打开发布中心」。
2. 进入「动态」，输入一段测试文案。可先不登录，验证本地编辑；仅浏览编辑功能无法覆盖平台同步。
3. 在「文章」导入本地 Markdown 文件，例如标题为“审核测试”、正文为“这是一份用于检查草稿同步的测试内容。”的 `.md` 文件。可选用不含个人数据的本地 PNG/JPEG 图片作为附件。
4. 修改标题、摘要或正文，检查预览结果。关闭发布中心后重新打开，确认当前草稿保留；在文章和动态之间切换，确认两类内容分别保留。

## 登录与普通账号测试

1. 在发布中心点击「去登录」，使用开发者在 Dashboard 私密测试说明中提供的审核专用 WeSight 普通账号，按 WeSight 登录页面要求完成验证。
2. 登录完成后应返回发布中心，右上角显示账号昵称或头像。账户菜单应显示普通账号每次同步 1 个平台。
3. 检查第三方平台卡片。未登录的目标平台应提供「去登录」；点击后在平台自己的页面完成登录。扩展不会填写登录表单。
4. 仅选择一个已登录且具有创作权限的平台，点击「开始同步」。平台编辑页应打开并进入准备过程；完成后检查文案、图片或文章草稿。请停留在草稿状态。
5. 切回发布中心，检查任务状态。需要登录或失败的平台可以处理原因后单独重试。
6. 尝试在普通账号中同时选择多个平台，验证会员提示及权益限制。可关闭提示，继续单平台流程。

## 动态图片与视频测试

1. 进入「动态」，使用一段测试文案和一张小于 5 MB 的 PNG/JPEG 图片。微博、即刻和 X 支持纯文字；小红书需要标题并附图片或视频。
2. 选择已登录的一个平台并同步，检查平台编辑页中的文案和图片。X 图片通过 X 自己的 Post 文件上传入口装入，最终发布保持人工确认。
3. 如需验证视频，选择小红书、微博或即刻，使用符合平台规则且小于 200 MB 的测试视频。视频与图片分开测试。等待平台上传和处理后检查草稿状态；X 动态当前会阻止视频同步。
4. 在「动态」点击「新内容」并确认，检查当前文案及素材引用被替换。该操作保留平台选择，且最近任务仍可能为重试引用此前素材。

## 链接导入与可选网站权限测试

1. 在「文章」输入一篇可公开访问且有权用于测试的文章链接，点击导入。
2. 首次使用时，浏览器会请求读取网页的可选权限。授权后扩展直接请求该网页和图片，并在本机生成草稿；拒绝权限时应提示无法读取链接，其余本地编辑功能可继续使用。
3. 检查标题、正文、图片及来源标识。不同网站的正文提取可能存在差异；登录或访问限制由来源网站决定。
4. 无需将导入内容发布到平台。若同步，请只使用获准测试的账号及内容。

## 会员多平台测试

使用开发者在 Dashboard 私密测试说明中提供的审核专用 WeSight 有效会员账号；审核账号应已具备权益，审核员无需购买。进入文章或动态模式，选择两个已登录且有相应创作权限的平台并同步，分别检查两个平台的草稿和任务状态。扩展不会为第三方平台提供付费创作权限。

## 可选测试：Obsidian 本机通道

1. 安装与当前扩展兼容的 WeSight Obsidian 插件，并使用审核专用有效会员账号登录。
2. 在 Obsidian 的「设置 → WeSight → 通用 → 连接器」点击浏览器发布助手的「连接浏览器」，完成配对。此步骤仅建立本机通道，不导入笔记或创建任务。
3. 使用测试 Markdown 笔记发起「多平台发布」，检查发布中心收到标题、正文及附件。动态交接可从「转为图文」生成平台文案后执行。
4. 检查内容并开始同步。正文与附件通过 `127.0.0.1` 导入，所选平台收到同步内容；任务状态可通过本机通道回传。
5. 关闭 Obsidian，检查扩展显示连接断开；再次打开并重新连接后应恢复。无需此步骤即可完成浏览器独立发布中心的主要功能测试。

## 退出和清除数据测试

在发布中心账户菜单点击「退出登录」，确认账号退出，而本机草稿和平台选择保留。退出操作清理扩展本机 WeSight 凭据及会员缓存，并尝试撤销服务器刷新令牌；各内容平台的网页登录状态独立保留。

移除扩展可清除其本机浏览器存储。该操作不会删除 Obsidian 原笔记、WeSight 云端账号或平台端已经保存的素材和草稿。账号数据请求可联系 hello@wesight.ai。

## 关于权限、远程请求和人工确认

- `storage` 用于草稿以外的配置、账号状态、凭据、有限日志及任务检查点；正文和附件保存在本机 IndexedDB。
- `alarms` 用于已配对 Obsidian 本机通道的定时连接检查。
- `scripting` 用于平台页面内的登录识别、编辑器适配、原生上传和平台草稿请求。
- `declarativeNetRequestWithHostAccess` 仅在 WeSight 登录期间，将本扩展创建的登录标签页回调定向至打包的扩展回调页，随后删除临时规则。
- 固定网站权限覆盖支持平台、WeSight 账号服务及本机通道；任意文章链接和其图片来源通过可选网站权限处理。具体权限以最终上传包的 `manifest.json` 及权限说明文件为准。
- X 文章需要读取 X 的公开脚本文本以解析接口配置。下载的文本只作为数据解析，不通过 `eval`、`Function` 或脚本标签执行。X 动态通过原生 Post 链接和文件上传控件准备内容。
- 账号和素材请求会联系对应服务；最终发布按钮由用户自行点击，扩展不调用正式发布接口。
